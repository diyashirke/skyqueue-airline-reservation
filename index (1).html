01 · Overview

Problem Statement & Objective

Problem

A flight has a fixed number of seats. When bookings exceed capacity, passengers must be handled fairly instead of being rejected. Manual handling is slow and error-prone, and cancellations should free seats for waiting passengers immediately.

Objective

Build a menu-driven C program that books and cancels tickets, keeps overflow passengers in a waitlist, and promotes them automatically in arrival order using a queue.

Queue (Linked-List Implementation)

A queue follows First In, First Out. The first passenger to join the waitlist is the first to get a seat.

Why a Queue?

Waitlists are naturally first-come-first-served. A queue guarantees fairness with no extra logic.

Why a Linked List?

The waitlist size is unknown in advance. Nodes are allocated with malloc only when needed, so no space is wasted.

Node Structure

03 · Algorithms

Algorithms Used

1

Enqueue

Adds a passenger at the rear of the waitlist when all seats are taken.

  1. Create a new node with malloc
  2. If queue is empty, set front = rear = node
  3. Else link rear→next to node, move rear
O(1)
2

Dequeue

Removes the passenger at the front when a seat becomes free.

  1. Check the queue is not empty
  2. Save front node, move front to front→next
  3. If queue is now empty, set rear = NULL
O(1)
3

Waitlist Promotion

On cancellation, the freed seat is given to the front of the queue.

  1. Cancel booking, mark seat free
  2. If waitlist is not empty, dequeue
  3. Assign the freed seat to that passenger
O(1)
4

Linear Search

Finds a booking (or waitlist entry) by ticket ID for cancellation.

  1. Scan seats one by one comparing ID
  2. If not found, scan the waitlist nodes
  3. Return the match or report not found
O(n)

    06 · Source Code

    Core Functions in C

    Key functions are shown here. The complete program is in airline.c.

    void enqueue(Queue *q, Passenger *p) {
    p->next = NULL;
    if (q->rear == NULL) {          /* empty queue */
        q->front = q->rear = p;
    } else {
        q->rear->next = p;          /* link at the end */
        q->rear = p;
    }
    q->size++;
}
    Passenger *dequeue(Queue *q) {
    if (q->front == NULL)           /* underflow */
        return NULL;

    Passenger *p = q->front;
    q->front = p->next;
    if (q->front == NULL)
        q->rear = NULL;             /* queue became empty */

    p->next = NULL;
    q->size--;
    return p;
}
    void cancelTicket(int id) {
    for (int i = 0; i < CAPACITY; i++) {
        if (seats[i] && seats[i]->ticketId == id) {
            printf("Ticket %d cancelled (seat %d).\n", id, i + 1);
            free(seats[i]);
            seats[i] = NULL;

            Passenger *next = dequeue(&waitlist);   /* promotion */
            if (next) {
                next->seatNo = i + 1;
                seats[i] = next;
                printf("%s promoted from waitlist to seat %d.\n",
                       next->name, i + 1);
            }
            return;
        }
    }
    /* otherwise search the waitlist ... (see airline.c) */
}

    08 · Conclusion

    Conclusion & Future Scope

    Conclusion

    The project shows how a queue models real-world fairness. Enqueue and dequeue run in constant time, so the waitlist stays fast no matter how many passengers join.

    Future Scope

    • Priority queue so senior or VIP passengers are promoted first
    • Multiple flights using a hash table of queues
    • Saving bookings to a file for permanent storage
    • Sorting passengers by name or seat number
